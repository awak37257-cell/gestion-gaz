# ⛽ Gestion Dépôt de Gaz

Application web de gestion de stock, de suivi des dépôts et de contrôle des ventes de bouteilles de gaz, développée avec **Laravel**.

## 🚀 Fonctionnalités principales

- **Authentification & Rôles** : Espace sécurisé pour les administrateurs et interface dédiée aux vendeurs.
- **Gestion des Dépôts & Stocks** : Suivi en temps réel des bouteilles disponibles (par marque, couleur et quantité).
- **Espace Vendeur (Mobile-First)** : Interface optimisée pour smartphone, conçue pour les vendeurs sur le terrain.
- **Système de QR Code** : Génération et gestion de jetons uniques pour identifier rapidement les transactions et les vendeurs.
- **Suivi des Demandes & Inventaires** : Historique des mouvements et validation des opérations.

## 🛠️ Technologies utilisées

- **PHP 8.3+**
- **Laravel 11 / 13** (Framework PHP)
- **MySQL** (Base de données)
- **Blade & CSS natif** (Design épuré et responsive, avec mode d'impression dédié)
